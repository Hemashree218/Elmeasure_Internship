# Elmeasure India Pvt. Ltd. — Internship

## 📌 Internship Overview

This repository contains the documentation and deliverables from my one-month industry internship at **Elmeasure India Pvt. Ltd.**

The internship provided hands-on exposure to:

- Software Testing
- Test Automation
- Python & PyTest
- Selenium WebDriver
- Page Object Model (POM)
- Git & GitHub
- SQL
- Jenkins
- Workflow Automation using n8n

The internship progressed from software testing and automation to workflow automation and exposure to AI-related applications.

## 🏢 Organization

**Elmeasure India Pvt. Ltd.**

Elmeasure is a technology company focused on smart and sustainable energy management solutions. Its product portfolio includes energy monitoring solutions, IoT energy meters, power quality products, network gateways and electrical control solutions.

During the internship, I was primarily exposed to software testing, web automation and workflow automation.
